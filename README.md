# PharmacyStock

Навчальний проєкт з дисципліни «Конструювання програмного забезпечення».

**Варіант №19:** Облік ліків і рецептів в аптеці.

## Опис проєкту

PharmacyStock — це консольна програма для обліку лікарських препаратів і рецептів в аптеці.

У програмі створено основні класи для зберігання інформації про пацієнтів, препарати та рецепти. Також реалізовано додавання препаратів до рецепта й обчислення їх загальної вартості.

## Структура проєкту

- **PharmacyStock.Core** — бібліотека класів, яка містить основну логіку програми.
- **PharmacyStock.App** — консольний застосунок для запуску та виведення результатів.
- **Domain** — папка з класами предметної області.

## Необхідні інструменти

Для роботи з проєктом використовуються .NET SDK 8.0, Visual Studio Code, C# Dev Kit та Git.

## Складання та запуск

Для складання проєкту використовується команда:

`dotnet build`

Для запуску програми:

`dotnet run --project PharmacyStock.App`

Після запуску програма виводить номер рецепта, його стан, кількість препаратів і загальну суму.

## Стандарт кодування

Основні правила написання коду описані у файлі `CODING_STANDARD.md`.

Для перевірки форматування використовується команда:

`dotnet format --verify-no-changes`

У проєкті застосовуються аналізатори Roslyn та StyleCop.
