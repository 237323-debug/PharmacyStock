# Метрики успадкованого модуля до рефакторингу

Проєкт: PharmacyStock, варіант 19.
Файл: `src/Legacy/LegacyPrescriptionProcessor.cs`.
Вимірювання: вручну за правилами лабораторної роботи № 6.
LOC: кількість непорожніх рядків без рядків, що містять тільки коментарі. Фігурні дужки враховуються як непорожні рядки.
CC: 1 + кількість точок розгалуження (`if`, `else if`, `for`, `foreach`, `&&`, `||` тощо).
Глибина: максимальна кількість вкладених керувальних блоків.

| Метод | LOC | CC | Глибина вкладеності | Параметрів |
|---|---:|---:|---:|---:|
| `Handle` | 80 | 17 | 4 | 11 |
| `Preview` | 28 | 9 | 2 | 3 |
| `DescribeClient` | 10 | 3 | 1 | 1 |
| `DumpLog` | 6 | 2 | 1 | 0 |
| Клас загалом | 130 | - | - | - |

## Розрахунок CC для Handle

| Точка розгалуження | Кількість |
|---|---:|
| `if (items != null)` | 1 |
| `if (items.Count > 0)` | 1 |
| `if (state == "new" \|\| state == "paid")` | 2 |
| `if (clientMail != null && ...)` | 2 |
| Два цикли `for` | 2 |
| Три перевірки виду клієнта (`if`, `else if`, `else if`) | 3 |
| Три перевірки обмеження знижки `> 500m` | 3 |
| `if` для доставки `< 1000m` | 1 |
| `if (sendMail)` | 1 |
| **Разом точок розгалуження** | **16** |

**CC = 1 + 16 = 17.**

## Додаткові спостереження

- Відповідальності: перевірка вхідних даних, обчислення суми, правила знижок, доставка, формування звіту, ведення журналу, опис пацієнта (7).
- Між `Handle` і `Preview` повторюються приблизно 14 рядків логіки знижок та доставки (без врахування суто форматувальних рядків).
- У розрахунках використано 7 різних магічних значень: `0.15m`, `0.30m`, `0.05m`, `500m`, `1000m`, `60m`, `10`.
- Формат `ToString("0.00")` залежить від поточної культури, а `DateTime.Now.Year` від системного часу. Це поки не змінюємо, а згодом заносимо до технічного боргу.
